محافظ گستران - بسته آماده ساخت APK در فضای ابری

این بسته شامل نسخه فعلی برنامه در پوشه www و فایل‌های لازم برای ساخت APK با GitHub Actions است.
ساخت در سرورهای GitHub انجام می‌شود؛ بنابراین روی گوشی نیازی به AndroidIDE، Android Studio، Java یا نصب ابزارهای حجیم نیست.

مراحل کلی:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) در GitHub یک مخزن (Repository) جدید و خالی بسازید.
3) محتویات داخل پوشه MohafezGostaran-CloudBuild را در ریشه مخزن قرار دهید؛ خود پوشه مادر را داخل مخزن نگذارید.
4) در مخزن، وارد Actions شوید و در صورت نمایش پیام، گزینه فعال‌سازی workflowها را بزنید.
5) از فهرست سمت چپ، Build MohafezGostaran APK را انتخاب کنید.
6) دکمه Run workflow و سپس دکمه سبز Run workflow را بزنید.
7) پس از پایان موفق ساخت، وارد همان اجرای workflow شوید و از بخش Artifacts فایل MohafezGostaran-APK را دانلود کنید.
8) ZIP دانلودشده را باز کنید؛ فایل app-debug.apk داخل آن است. روی APK بزنید تا نصب شود.

نکته‌ها:
- این APK برای نصب و آزمایش مستقیم روی گوشی ساخته می‌شود؛ نسخه انتشار فروشگاه نیست.
- چون داده‌ها در حافظه محلی برنامه ذخیره می‌شوند، قبل از حذف یا نصب مجدد برنامه از بخش پشتیبان‌گیری خروجی بگیرید.
- این مرحله فقط بسته‌بندی فعلی وب‌اپ است. باید روی گوشی واقعی نصب و قابلیت‌هایی مانند چاپ و اشتراک‌گذاری فاکتور جداگانه آزمایش شوند.
- فایل app-debug.apk با امضای آزمایشی ساخته می‌شود. برای انتشار عمومی و به‌روزرسانی پایدار باید بعداً کلید امضای اختصاصی ایجاد و امن نگهداری شود.
